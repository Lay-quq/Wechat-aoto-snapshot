# 本机微信连接探测

本组件只返回当前运行微信唯一使用的账号数据库目录，供一键连接使用。它不启动微信，不读取数据库正文或密钥，不修改进程、窗口或数据库，也不发送消息或授予发送权限。

`ConnectionProbe.cs` 基于本仓库 `tools/wechat-native-helper/NativeProbe.cs` 的只读句柄扫描；公共 Win32 声明、句柄表解析和数据库路径/证据校验通过项目源文件链接复用。它是单独构建的可执行程序，不改动原生发送组件、发送接受状态或信任摘要。

当前匹配已支持的微信 4.1.15.56。两次完整活动句柄扫描以及进程/窗口/模块复核一致，并且只有一个账号目录具有完整 contact/session/message 数据库族时才返回目录。旧目录、最近修改时间、当前保存账号均不能充当运行账号证据。多个活动账号或证据不完整会给出短错误提示，不猜测一个账号。

唯一输入为 `{"id":"UUID","method":"discover","params":{}}`。输出的账号目录属于主进程内部数据，不传至 UI、模型或公开日志。账号数据库没有被打开读取；仅已加载的微信程序 DLL 会被读取用于版本核对。宿主限定运行时间、输出大小和取消信号。

构建及纯合成验证：`node scripts/build-wechat-connection-helper.cjs`。构建产物放在 `resources/wechat-connection/win32-x64`，由现有 resources 打包规则带入应用；普通开源版不需要用户额外安装 .NET。
